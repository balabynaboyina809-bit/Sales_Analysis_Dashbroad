# Sales Analytics Dashboard Using SQL

## Overview

This project is a SQL-based Sales Analytics Dashboard designed to manage,
analyze, and generate useful insights from retail sales data.

## Project Statement

A retail company sells electronic products across different cities through multiple sales representatives. The company has years of sales data but currently does not have a proper reporting system.

Management wants a database system to store customer information, product details, employee information, orders, and order item transactions to improve sales analysis and support better business decisions.

My job as a SQL Data Analyst is to design the database, organize the data, analyze sales performance, and generate reports that answer important business questions.

## Project Objectives

Design a relational database and generate reports that help management understand:

1. Which products sell the most?
2. Which products generate the most revenue?
3. Which customers generate the most revenue?
4. Which cities perform best?
5. What are the monthly sales trends?
6. What is the performance of each employee?
7. Which product categories generate the most revenue?
8. What is the customer purchasing behavior?

## Database Tables

The project contains the following main tables:

* **Customers** – Stores customer details such as customer ID, name, city, and email.
* **Products** – Stores product information including product name, category, and price.
* **Employees** – Stores employee information and their regions.
* **Orders** – Stores order information, customer, employee, and order date.
* **Order Items** – Stores products and quantities associated with each order.

The database uses primary keys and foreign keys to maintain relationships between the tables.

## Business Analysis

SQL queries were created to answer important sales-related business questions, including:

* Identifying the products with the highest number of units sold.
* Finding the products that generate the highest revenue.
* Identifying customers who generate the most revenue.
* Comparing revenue performance across different cities.
* Analyzing monthly sales trends.
* Measuring employee revenue performance.
* Analyzing revenue by product category.
* Understanding customer purchasing behavior.

These analyses are implemented using SQL joins, aggregate functions, `GROUP BY`, `ORDER BY`, `SUM()`, and `COUNT()` functions.
